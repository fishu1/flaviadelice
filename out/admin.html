Panou de administrare

📷 Cum adaugi imagini în galerie

  1. Deschide folderul public/uploads/ din proiect
  2. Creează un subfolder cu numele prăjiturii (ex: tort-ciocolata)
  3. Pune imaginile în acel subfolder
  4. Rulează npm run build în terminal
  5. Uploadează folderul out/ pe cPanel

✍️ Cum adaugi un articol pe blog

  1. Deschide folderul content/blog/ din proiect
  2. Creează un fișier nou nume-articol.json
  3. Completează cu structura de mai jos
  4. Rulează npm run build în terminal
  5. Uploadează folderul out/ pe cPanel

Structura fișierului JSON:

{
  "title": "Titlul articolului",
  "introduction": "Descriere scurtă",
  "content": "Conținutul articolului..."
}

Shortcode pentru card produs în content:

[produs nume="Nume" imagine="/uploads/img.jpg" descriere="Descriere" link="https://..."]
